## 1. 関連商品の選択肢をカテゴリごとに分ける

場所: 管理画面の「収集・AI判定」→ 記事を開く →「関連商品（記事ページに PR として表示）」

- 商品のチェックボックスを、カテゴリの見出しごとにまとめて並べる。
- カテゴリは名前の順。カテゴリが空の商品は、最後の「その他」にまとめる。
- カテゴリが複数ある商品は、それぞれのカテゴリの下に出る。

変えたファイル: `ts/src/views/inbox.ts`（`byCategory()`）、`ts/src/styles.css`

## 2. 商品のカテゴリを複数選べるようにする

場所: 管理画面の「商品・リンク」→ 追加・編集

- 登録済みの商品のカテゴリを、チェックボックスで複数選べる。
- 一覧に無いカテゴリは、下の入力欄に入れる。カンマ（`,` または `、`）で区切れば、複数まとめて入れられる。
- DB の `products.category` には `書籍, IT` のように、カンマ区切りで入れる。列は今の text のまま（配列の列には変えていない）。同じカテゴリが 2 回入っていたら 1 つにまとめる。
- `・` は区切りの文字にしていない。「書籍・IT・教育」は 1 つのカテゴリとして扱う。3 つに分けたいときは、編集画面でそのチェックを外し、`書籍, IT, 教育` と入れ直す。

公開サイトでの見え方:

| 場所 | 見え方 |
|---|---|
| おすすめ商品（`/products`） | 商品が、それぞれのカテゴリの見出しの下に出る |
| 商品カード | `書籍 / IT` のように並べて出す |

変えたファイル:
- `ts/src/views/products.ts`（`categoriesOf()`、編集画面）
- `ts/src/views/inbox.ts`
- `site/src/html.ts`（`categoriesOf()`、商品カード）
- `site/src/pages.ts`（おすすめ商品のカテゴリ分け）

カンマで分ける処理（`categoriesOf()`）は、管理画面と公開サイトに 1 つずつある。区切りの文字を変えるときは、両方を直す。

## 3. 記事ページに関連記事を出す

場所: 公開サイトの記事ページ（`/a/<番号>`）。日本語は「あわせて読みたい」、英語は「More to read」。

- 最大 4 件（`site/src/pages.ts` の `RELATED`）。
- 同じペルソナの新しい記事を先に出し、足りない分は、そのサイトのほかの新しい記事で埋める。
- 開いている記事自身と、重複は除く。ほかのサイトの記事は出ない。
- 見た目は、トップページの記事カードと同じ。

変えたファイル: `site/src/pages.ts`、`site/src/text.ts`、`site_adoutor/src/text.ts`（見出しの文言 `relatedArticles`）
