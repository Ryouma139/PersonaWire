# Persona Wire 管理画面

NEWS × SNS CURATION — ニュースとSNSを収集し、ペルソナ別にAIが判定・キュレーションして、公開サイトと有料配信に届けるための管理画面（フロントエンドのモック実装）。

## 起動

ビルド不要です。`index.html` をブラウザで開くだけで動きます。

```
start index.html
```

データはモックで、変更内容はブラウザの localStorage（`persona-wire:v1`）に保存されます。初期状態に戻すにはコンソールで `PW.store.reset()` を実行してください。

## 画面

| グループ | 画面 | ハッシュ | 主な機能 |
|---|---|---|---|
| 運用 | ダッシュボード | `#dashboard` | KPI、7日間の収集/採用推移、ペルソナ別状況、配信予定、アクティビティ |
| 運用 | 収集・AI判定 | `#inbox` | 今すぐ収集、ステータスタブ・絞り込み・検索、ペルソナ別スコア/しきい値、採用・却下・公開、一括操作、配信号への追加 |
| 運用 | 有料配信 | `#delivery` | プラン管理、配信号の編集（記事の追加・並べ替え）、メールプレビュー、予約・即時配信 |
| 設定 | ペルソナ | `#personas` | 関心キーワード・NGワード・トーン・採用しきい値・カラーの設定、有効/無効 |
| 設定 | 商品・リンク | `#products` | アフィリエイトリンクの登録、ペルソナ割当、クリック/CV、計測リンクのコピー |
| 設定 | Notion連携 | `#notion` | 接続/解除、手動・自動同期、DB対応と同期方向、プロパティ対応、同期ログ |
| 確認 | 公開サイト | `#site` | PC/スマホ表示切替、ペルソナ別ページ、有料購読CTA、おすすめ商品 |

## 構成

```
index.html              シェル（サイドバー + ビュー領域）
assets/styles.css       スタイル（ライト/ダーク対応、レスポンシブ）
assets/js/store.js      モックデータ・状態管理・AI判定ロジック
assets/js/ui.js         共通ヘルパー（モーダル、トースト、バッジ等）
assets/js/app.js        ハッシュルーター
assets/js/views/*.js    各画面
```

AI判定・収集・Notion同期・配信はすべてシミュレーションです。実際のAPI（LLM、Notion API、メール配信など）に接続する場合は `store.js` の `collect` / `judge` と各ビューの同期・配信処理を差し替えてください。
